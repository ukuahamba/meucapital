# MeuCapital

Site de gestão financeira pessoal inspirado no painel apresentado.

## Estrutura
- `index.html` — página principal e SEO básico
- `style.css` — visual responsivo
- `script.js` — calculadora e simulador

## Publicação
Este projeto é um site estático e pode ser publicado no GitHub Pages, Netlify, Vercel ou outro serviço de hospedagem estática.

Antes de publicar, substitui no `index.html`:
`https://SEU-DOMINIO-AQUI/`
pelo domínio real do site.

Para aparecer no Google, depois da publicação:
1. adiciona o site ao Google Search Console;
2. verifica a propriedade do domínio;
3. envia o sitemap (quando adicionarmos um);
4. solicita a indexação da página inicial.

## Nota
Os valores mostrados são exemplos. Para guardar dados reais de utilizadores, será necessário acrescentar uma base de dados e autenticação segura.
